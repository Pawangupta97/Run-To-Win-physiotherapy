== Installation Instructions ==

Method 1: Upload via WordPress Admin (Recommended)
1. Download `run-to-win-physio.zip`.
2. Log into your WordPress Admin Dashboard (e.g., `yourwebsite.com/wp-admin`).
3. Navigate to **Appearance** > **Themes** in the left sidebar.
4. Click **Add New Theme** at the top, then click **Upload Theme**.
5. Click **Choose File**, select `run-to-win-physio.zip`, and click **Install Now**.
6. Click **Activate**.
7. Go to **Settings** > **Reading** and ensure your homepage displays the latest front page.

Method 2: Upload via FTP / cPanel File Manager
1. Unzip `run-to-win-physio.zip`.
2. Upload the `run-to-win-physio` folder to your `/wp-content/themes/` directory on your server.
3. Log into WP Admin > Appearance > Themes, find **Run To Win Physiotherapy**, and click **Activate**.

== Configuration ==
- To customize the WhatsApp number or clinic email, edit `functions.php` or `footer.php`.
- The theme automatically registers responsive navigation menus and handles appointment booking notifications directly to your WordPress administrator email.
